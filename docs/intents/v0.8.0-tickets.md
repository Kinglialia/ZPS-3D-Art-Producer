# Tickets: v0.8.0

Intent and task list: `docs/intents/v0.8.0-plan.md`. Decisions: `docs/decisions.md` D36–D45.
`S` = `src/zps-3dp-producer`. Spec branch: `feat/v0.8.0`, cut from `main` at `3a0b60f` or later. Every commit ends with a `Ticket: <NN>` trailer. Tickets are K01–K26; the letter K keeps them apart from the plan's texture rows T1–T19.

A row id (R1, C4, B2, …) is a row of the plan. The **Acceptance** of a ticket is every row it lists, with the test that row names. This file adds only what the plan does not say.

Rows with no ticket: S1, S5 and U1 are done on `main`. A2 and A4 follow the pilots (last section).

## Shared rules for every ticket

- Read the plan section of your rows first, then the decision the section names. The spec is in Vietnamese.
- Write a test that fails before you change code. The test says why the behaviour matters. A test that passes when the function under test returns nothing is not accepted.
- Rows marked **đoán** in the plan: reproduce the defect first. If you cannot reproduce it, do not change code. Report it.
- Do not edit a kit file listed under "Chép nguyên" in a `SOURCE.md`. Put the change in a tool beside it.
- Do not edit files outside **Writes**. Report anything else as a follow-up.
- No comment that narrates code. Comment only a non-obvious why.
- Keep `P` output and tool output short. One line when the result is a pass.
- Text for agents (agent files, references, `SKILL.md`, briefs) is Vietnamese, short sentences, one idea each. Do not add decision tags ("D31.3") to it.
- Classify every change by D34.1. Nothing in this file is for one asset.
- Report a **Spec notes** section: any row that is not needed, any contradiction, any output nobody reads. Do not change the spec.

## Test command

`S/scripts/.deps/venv/bin/python -m pytest -q -p no:cacheprovider -m "not blender" tests` from the worktree root.

- Baseline at `3a0b60f`: 1178 passed, 33 deselected.
- The venvs (`**/.deps/`) and `upstream/` are gitignored. A worktree does not have them. Before the run, symlink them from the root checkout. Remove the symlinks after the run. `git status` must be clean.
- Tickets marked **blender** also run `-m blender` for their own `tests/<step>/` folder. This needs Blender on the machine. Report "not run" when Blender is missing. Do not report green.
